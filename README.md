# OruPaad-LeafTHANda 🎯

## Basic Details
### Team Name: TimeX

### Team Members
- Team Lead: Prajod Prakash - Providence college of engineering
- Member 2: Joyal Francis - Providence college of engineering

### Project Description
A sophisticated web application that uses computer vision to detect, measure, and analyze the empty space between palm leaf strips. It assigns humorous "personalities" to the gaps and calculates a "Uselessness Score" based on how meticulously it over-analyzed botanical nothingness.

### The Problem (that doesn't exist)
Nobody knows the exact millimeter width of the empty space between palm leaf strips, leaving humanity in a state of agonizing botanical ignorance. How can we sleep at night without knowing the average inter-leaflet separation?

### The Solution (that nobody asked for)
We built a fully client-side computer vision pipeline! You upload a picture of a palm leaf next to a ₹1 coin. The system automatically detects the coin for real-world scale calibration, segments the green leaf, measures the microscopic empty voids, and generates completely unnecessary scientific-sounding conclusions.
